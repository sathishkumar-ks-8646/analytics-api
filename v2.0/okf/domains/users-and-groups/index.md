# Users & Groups

* [Users & Groups](overview.md) - API for managing users and groups in Zoho Analytics — covering org-level users, workspace-level users, and workspace groups.

# Subdirectories

* [Organization Users](org-users/index.md) - APIs that allow the Account Admin and the Organization Admins of a Zoho Analytics organization to manage its users - listing, adding, removing, activating, deactivating and changing the org-level role of the users, and listing the users who hold the Organization Admin role.
* [Custom Roles](custom-roles/index.md) - APIs that allow the Account Admin and the Organization Admins of a Zoho Analytics organization to define custom roles - named permission bundles that can be granted to users in place of the built-in roles.
* [Workspace Users](workspace-users/index.md) - APIs that manage the users and the administrators of a single Zoho Analytics workspace - controlling who has access to the workspace, the role they hold within it, and whether that access is currently active.
* [Workspace Groups](workspace-groups/index.md) - APIs that manage the groups of a Zoho Analytics workspace.
