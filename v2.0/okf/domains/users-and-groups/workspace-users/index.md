# Workspace Users

* [Workspace Users](overview.md) - APIs that manage the users and the administrators of a single Zoho Analytics workspace - controlling who has access to the workspace, the role they hold within it, and whether that access is currently active.

# Concepts

* [Add Workspace Admins](add-workspace-admins.md) - Grants the Workspace Admin role to one or more users in the specified workspace.
* [Add Workspace Users](add-workspace-users.md) - Adds one or more users to the specified workspace with a given workspace-level role.
* [Change Workspace Users Role](change-workspace-users-role.md) - Changes the workspace-level role of one or more users in the specified workspace.
* [Change Workspace Users Status](change-workspace-users-status.md) - Activates or deactivates one or more users in the specified workspace.
* [Remove Workspace Users](delete-workspace-users.md) - Removes one or more users from the specified workspace.
* [Get Workspace Admins](get-workspace-admins.md) - Returns the users who currently hold the Workspace Admin role in the specified workspace, grouped by domain context.
* [Get Workspace Users](get-workspace-users.md) - Returns the list of all the users who have access to the specified workspace, along with their workspace-level role and active status.
* [Remove Workspace Admins](remove-workspace-admins.md) - Revokes the Workspace Admin role from one or more users in the specified workspace.
