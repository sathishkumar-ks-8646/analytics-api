# Workspace Groups

* [Workspace Groups](overview.md) - APIs that manage the groups of a Zoho Analytics workspace.

# Concepts

* [Add Group Members](add-group-members.md) - Adds one or more users to an existing group.
* [Create Group](create-group.md) - Creates a new group in the specified workspace and adds the initial members to it.
* [Delete Group](delete-group.md) - Permanently deletes a group from the workspace.
* [Get Group Details](get-group-details.md) - Returns the full details of a single group - its name, description and complete member list.
* [Get Group List](get-groups.md) - Returns all the groups defined in the specified workspace, along with their descriptions and current member lists.
* [Remove Group Members](remove-group-members.md) - Removes one or more members from a group.
* [Rename Group](rename-group.md) - Updates the name and the description of an existing group in the specified workspace.
