# Organization Users

* [Organization Users](overview.md) - APIs that allow the Account Admin and the Organization Admins of a Zoho Analytics organization to manage its users - listing, adding, removing, activating, deactivating and changing the org-level role of the users, and listing the users who hold the Organization Admin role.

# Concepts

* [Activate Users](activate-users.md) - Reactivates one or more previously deactivated users in the specified organization.
* [Add Users](add-users.md) - Adds one or more users to the specified organization.
* [Change User Role](change-user-role.md) - Changes the org-level role of one or more users in the specified organization.
* [Deactivate Users](de-activate-users.md) - Deactivates one or more users in the specified organization.
* [Get Org Admins](get-org-admins.md) - Returns the email addresses of the users who currently hold the Organization Admin role in the specified organization.
* [Get Users](get-users.md) - Returns the list of all the users who are members of the specified organization, along with their current status and org-level role.
* [Remove Users](remove-users.md) - Removes one or more users from the specified organization.
