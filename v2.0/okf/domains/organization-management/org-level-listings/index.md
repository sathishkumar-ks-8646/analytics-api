# Org-Level Listings

* [Org-Level Listings](overview.md) - APIs that list, for one organisation, the workspaces the calling user can reach, the dashboards across those workspaces, and the views the user opened most recently.

# Concepts

* [Get Org Dashboards](get-org-dashboards.md) - Returns the dashboards of one organisation that the calling user may read, across all of the workspaces the caller can see or across the workspaces named in workspaceIds.
* [Get Org Recent Items](get-org-recent-items.md) - Returns the views the calling user opened most recently in one organisation, of any view type, newest first.
* [Get Org Workspaces](get-org-workspaces.md) - Returns the workspaces of one organisation that the calling user can reach.
