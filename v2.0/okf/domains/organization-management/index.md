# Organization Management

* [Organization Management](overview.md) - APIs that return information about the resource usage, subscription plan, and workspace or view identity lookups available within an organisation, that list the workspaces, dashboards and recently opened views the calling user can reach in that organisation, and that read and update the organisation-wide and per-workspace access restriction settings.

# Subdirectories

* [Organization Info & Settings](org-info-and-settings/index.md) - APIs for retrieving organisation information, resource usage, subscription details, and workspace or view metadata.
* [Org-Level Listings](org-level-listings/index.md) - APIs that list, for one organisation, the workspaces the calling user can reach, the dashboards across those workspaces, and the views the user opened most recently.
* [Security Controls](security-controls/index.md) - APIs for reading and updating the access restriction settings of an organisation and of an individual workspace - sharing, private links, public views, export and email.
