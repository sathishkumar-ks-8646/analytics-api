# Organization Management

* [Organization Management](overview.md) - APIs that return information about the organisations, resource usage, subscription plan, and workspace or view identity lookups available to the authenticated user, and that read and update the organisation-wide and per-workspace access restriction settings.

# Subdirectories

* [Organization Info & Settings](org-info-and-settings/index.md) - APIs for retrieving organisation information, resource usage, subscription details, and workspace or view metadata.
* [Security Controls](security-controls/index.md) - APIs for reading and updating the access restriction settings of an organisation and of an individual workspace - sharing, private links, public views, export and email.
