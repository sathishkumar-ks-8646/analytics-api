# Security Controls

* [Security Controls](overview.md) - APIs for reading and updating the access restriction settings of an organisation and of an individual workspace - sharing, private links, public views, export and email.

# Concepts

* [Get Org Access Restrictions](get-org-access-restrictions.md) - Returns the organisation's access restriction settings: the master switch and the five sections.
* [Get Workspace Access Restrictions](get-workspace-access-restrictions.md) - Returns the access restriction settings in effect for one workspace and whether they come from the organisation or from the workspace.
* [Update Org Access Restrictions](update-org-access-restrictions.md) - Switches the organisation's access restrictions on or off and updates any of the five sections.
* [Update Workspace Access Restrictions](update-workspace-access-restrictions.md) - Switches one workspace between following the organisation and having its own settings, and updates the workspace's own sections.
