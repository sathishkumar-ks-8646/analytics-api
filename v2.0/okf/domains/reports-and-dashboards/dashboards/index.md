# Dashboards

* [Dashboards](overview.md) - APIs for creating a dashboard, reading its stored layout, settings and themes, replacing any of those three sections, and listing the dashboards a user owns or can see.

# Concepts

* [Create Dashboard](create-dashboard.md) - Creates a dashboard in the given workspace and returns its ID.
* [Read Dashboard Metadata](get-dashboard-metadata.md) - Returns the stored configuration of a dashboard.
* [Get All Dashboards](get-dashboards.md) - Returns all dashboards accessible to the authenticated user - both those owned by the user and those shared with them - across every organization and workspace.
* [Get Owned Dashboards](get-owned-dashboards.md) - Returns the list of dashboards owned by the authenticated user across every organization, as a single views array.
* [Get Shared Dashboards](get-shared-dashboards.md) - Returns all dashboards that have been shared with the authenticated user across every organization and workspace, as a single views array.
* [Update Dashboard](update-dashboard.md) - Replaces one or more sections of an existing dashboard.
