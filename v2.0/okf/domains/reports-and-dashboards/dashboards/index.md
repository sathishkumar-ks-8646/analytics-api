# Dashboards

* [Dashboards](overview.md) - APIs for listing dashboards accessible to a user, and for creating, reading and updating dashboards inside a workspace.

# Concepts

* [Create Dashboard](create-dashboard.md) - Creates a new dashboard in the specified workspace.
* [Get Dashboard Metadata](get-dashboard-metadata.md) - Retrieves the stored configuration of a dashboard in the specified workspace - its identity attributes, the visual theme, the layout card map and the behaviour settings.
* [Get All Dashboards](get-dashboards.md) - Returns all dashboards accessible to the authenticated user - both those owned by the user and those shared with them - across every organization and workspace.
* [Get Owned Dashboards](get-owned-dashboards.md) - Returns the list of dashboards owned by the authenticated user across every organization, as a single views array.
* [Get Shared Dashboards](get-shared-dashboards.md) - Returns all dashboards that have been shared with the authenticated user across every organization and workspace, as a single views array.
* [Update Dashboard](update-dashboard.md) - Updates an existing dashboard in the specified workspace.
