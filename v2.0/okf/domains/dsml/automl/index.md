# AutoML

* [AutoML](overview.md) - APIs for creating, running, deploying, and managing AutoML analyses and models.

# Concepts

* [AutoML What If Analysis](auto-ml-what-if-analysis.md) - Generates a prediction using a trained AutoML model.
* [Create AutoML Analysis Deployment](create-auto-ml-analysis-deployment.md) - Creates a deployment for an AutoML analysis model.
* [Create AutoML Analysis](create-auto-ml-analysis.md) - Creates a new AutoML analysis within the workspace.
* [Delete AutoML Analysis Model Deployment](delete-auto-ml-analysis-model-deployment.md) - Deletes an AutoML analysis deployment.
* [Delete AutoML Analysis Model](delete-auto-ml-analysis-model.md) - Deletes a specific model from an AutoML analysis.
* [Delete AutoML Analysis](delete-auto-ml-analysis.md) - Deletes the specified AutoML analysis from the workspace.
* [Get AutoML Analysis Details](get-auto-ml-analysis-details.md) - Retrieves the detailed information of a specific AutoML analysis, including the training table, the target column, the input features and every model trained under the analysis with its score and hyperparameters.
* [Get AutoML Analysis In Org](get-auto-ml-analysis-in-org.md) - Returns all the AutoML analyses available in the organization.
* [Get AutoML Analysis In Workspace](get-auto-ml-analysis-in-workspace.md) - Returns the list of AutoML analyses available in the specified workspace.
* [Get Deployments For A Model](get-deployments-for-model.md) - Returns the deployment details configured for an AutoML analysis model, including the input and output tables, the schedule status and the time at which the deployment last ran.
* [Run AutoML Analysis](run-auto-ml-analysis.md) - Executes an AutoML analysis deployment on demand.
