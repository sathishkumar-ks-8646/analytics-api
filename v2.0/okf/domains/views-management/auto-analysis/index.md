# Auto Analysis

* [Auto Analysis](overview.md) - APIs to automatically generate a curated set of views - charts, pivot tables and summary views - from an entire table or from a single column of it.

# Concepts

* [Auto Analyse Column](auto-analyse-column.md) - Triggers auto analysis for a single column of a table.
* [Auto Analyse View](auto-analyse-view.md) - Triggers auto analysis on an entire table.
