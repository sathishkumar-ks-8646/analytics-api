# Trash Management

* [Trash Management](overview.md) - APIs to list the views available in the trash of a workspace, restore a trashed view back to the workspace, and permanently delete a view from the trash.

# Concepts

* [Delete Trash View](delete-trash-view.md) - Permanently deletes the specified view from the trash.
* [Get Trash Views](get-trash-views.md) - Returns the list of all views available in the trash of the specified workspace, along with the time each view was deleted and the user who deleted it.
* [Restore Trash View](restore-trash-view.md) - Restores the specified view from the trash back into the workspace.
