# Views Management

* [Views Management](overview.md) - API for Views Management in Zoho Analytics — covering view operations, auto analysis, favorites, and trash management.

# Subdirectories

* [View Operations](view-operations/index.md) - APIs for creating, copying, renaming, deleting, and retrieving views.
* [View Preferences](view-preferences/index.md) - APIs to mark a view as a favorite for the authenticated user and to remove it from the favorites list.
* [Trash Management](trash-management/index.md) - APIs to list the views available in the trash of a workspace, restore a trashed view back to the workspace, and permanently delete a view from the trash.
* [Auto Analysis](auto-analysis/index.md) - APIs to automatically generate a curated set of views - charts, pivot tables and summary views - from an entire table or from a single column of it.
* [Tags](tags/index.md) - APIs to create, update, delete and list the tags of a workspace, and to attach those tags to views.
