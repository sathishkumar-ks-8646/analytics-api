# View Preferences

* [View Preferences](overview.md) - APIs to mark a view as a favorite for the authenticated user and to remove it from the favorites list.

# Concepts

* [Add Favourite View](add-favorite-view.md) - Marks the specified view as a favorite for the authenticated user.
* [Remove Favourite View](remove-favorite-view.md) - Removes the specified view from the favorites list of the authenticated user.
