# View Operations

* [View Operations](overview.md) - APIs for creating, copying, renaming, deleting, and retrieving views.

# Concepts

* [Copy Views](copy-views.md) - Copies one or more views from a source workspace to a destination workspace.
* [Create Similar Views](create-similar-views.md) - Replicates, for a target table, every analysis view - chart, pivot table, summary view and so on - that exists on a reference table in the same workspace.
* [Delete View](delete-view.md) - Deletes a view from a workspace.
* [Get Recent Views](get-recent-views.md) - Returns the views most recently accessed by the authenticated user, ordered with the most recent first.
* [Get View Dependents](get-view-dependents.md) - Returns every active view that depends on the specified view.
* [Get View Details](get-view-details.md) - Returns the metadata of a single view identified by its view ID.
* [Get View URL](get-view-url.md) - Generates and returns the publicly accessible URL of a view.
* [Get View List](get-views.md) - Returns the list of views accessible to the authenticated user within a workspace, together with the folder, creator and last-modifier metadata of each view.
* [Rename View](rename-view.md) - Renames an existing view and, optionally, updates its description.
* [Save As View](save-as-view.md) - Creates a copy of an existing view - a table or an analysis view - within the same workspace.
