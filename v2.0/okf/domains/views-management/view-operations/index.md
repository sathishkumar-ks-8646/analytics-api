# View Operations

* [View Operations](overview.md) - APIs for creating, copying, renaming, deleting, and retrieving views.

# Concepts

* [Copy Views](copy-views.md) - Copies one or more views from a source workspace to a destination workspace.
* [Create Similar Views](create-similar-views.md) - Creates copies of all analysis views (charts, pivot tables, summaries, etc.) that exist on a reference table and replicates them for a target table within the same workspace.
* [Delete View](delete-view.md) - Permanently deletes a view from a workspace.
* [Get Recent Views](get-recent-views.md) - Returns a list of views recently accessed by the authenticated user across all workspaces the user has access to, sorted by access time (most recently accessed first).
* [Get View Dependents](get-view-dependents.md) - Returns all active views that depend on the specified view.
* [Get View Details](get-view-details.md) - Returns detailed metadata for a single view identified by its view ID.
* [Get View URL](get-view-url.md) - Generates and returns the publicly accessible URL for a view.
* [Get View List](get-views.md) - Returns a list of views accessible to the authenticated user within a specific workspace.
* [Rename View](rename-view.md) - Renames an existing view and optionally updates its description.
* [Save As View](save-as-view.md) - Creates a copy of an existing view (table or analysis view) within the same workspace.
