# Tags

* [Tags](overview.md) - APIs to create, update, delete and list the tags of a workspace, and to attach those tags to views.

# Concepts

* [Add Tag To Multiple Views](add-tag-to-views.md) - Attaches one tag to a batch of views.
* [Add Multiple Tags To View](add-tags-to-view.md) - Attaches a batch of tags to one view.
* [Create Tag](create-tag.md) - Creates one tag in the workspace.
* [Delete Tag](delete-tag.md) - Deletes a tag and every association it has.
* [Get Tagged Views](get-tagged-views.md) - Returns the views that carry a given tag.
* [Get Tags List](get-tags.md) - Returns every tag that exists in the workspace.
* [Get View Tags](get-view-tags.md) - Returns the tags attached to a given view.
* [Remove Tag From Multiple Views](remove-tag-from-views.md) - Detaches one tag from a batch of views, or from every view at once.
* [Remove Multiple Tags From View](remove-tags-from-view.md) - Detaches a batch of tags from one view, or clears the view entirely.
* [Update Tag](update-tag.md) - Renames a tag, recolours it, or both.
