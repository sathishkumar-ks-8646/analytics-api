# Workspace Operations

* [Workspace Operations](overview.md) - APIs that manage the lifecycle and the metadata of workspaces, covering the creation, copying, renaming, deletion and inspection of a workspace.

# Concepts

* [Copy Workspace](copy-workspace.md) - Creates a copy of an existing workspace, either within the same organization or in a different organization.
* [Create Workspace](create-workspace.md) - Creates a new empty workspace in the specified organization.
* [Delete Workspace](delete-workspace.md) - Permanently deletes the specified workspace along with all its contents, including the tables, views, dashboards, formulas, import configurations and sharing settings.
* [Export as Template](export-as-template.md) - Exports the selected views of the specified workspace as a reusable template file in the .atpt (Zoho Analytics Template) format.
* [Get All Workspace List](get-all-workspaces.md) - Returns all the workspaces accessible to the requesting user, covering both the workspaces they own or administer and the workspaces shared with them.
* [Get Owned Workspace List](get-owned-workspaces.md) - Returns all the workspaces present in the organization of the requesting user, irrespective of how they are shared.
* [Get Shared Workspace List](get-shared-workspaces.md) - Returns all the workspaces that have been shared with the requesting user from other organizations.
* [Get Workspace Info](get-workspace-details.md) - Returns the metadata of the specified workspace.
* [Get Workspace Secret Key](get-workspace-secret-key.md) - Returns the secret key of the specified workspace.
* [Rename Workspace](rename-workspace.md) - Updates the name and the description of an existing workspace.
