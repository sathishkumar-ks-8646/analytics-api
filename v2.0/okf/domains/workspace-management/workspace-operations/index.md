# Workspace Operations

* [Workspace Operations](overview.md) - APIs that manage the lifecycle and the metadata of workspaces, covering the creation, copying, renaming, deletion and inspection of a workspace.

# Concepts

* [Copy Workspace](copy-workspace.md) - Creates a copy of an existing workspace.
* [Create Workspace](create-workspace.md) - Creates a new empty workspace in the specified organisation.
* [Delete Workspace](delete-workspace.md) - Permanently deletes the specified workspace and all of its contents — tables, views, dashboards, formulas, import configurations, and all sharing settings.
* [Export as Template](export-as-template.md) - Exports selected views from the specified workspace as a reusable template file.
* [Get Workspace Info](get-workspace-details.md) - Returns metadata for the specified workspace.
* [Get Workspace Secret Key](get-workspace-secret-key.md) - Returns the secret key for the specified workspace.
* [Rename Workspace](rename-workspace.md) - Updates the name and/or description of an existing workspace.
