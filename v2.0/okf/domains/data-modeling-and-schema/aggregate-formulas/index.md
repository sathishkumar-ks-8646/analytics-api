# Aggregate Formulas (Unified Metrics)

* [Aggregate Formulas (Unified Metrics)](overview.md) - APIs for managing aggregate formulas and retrieving values and dependents.

# Concepts

* [Add Aggregate Formula](add-aggregate-formula.md) - Creates a new aggregate formula owned by the specified view.
* [Delete Aggregate Formula](delete-aggregate-formula.md) - Permanently deletes an aggregate formula from the specified view.
* [Edit Aggregate Formula](edit-aggregate-formula.md) - Updates an existing aggregate formula.
* [Get Aggregate Formula Dependents](get-aggregate-formula-dependents.md) - Returns all views, dashboards, and other aggregate formulas that depend on the specified aggregate formula, along with the parent table(s) it is built from.
* [Get Aggregate Formula](get-aggregate-formula-list.md) - Returns the list of aggregate formulas defined on the specified view.
* [Get Aggregate Formula Value](get-aggregate-formula-value.md) - Computes and returns the current live value of the specified aggregate formula by executing its expression against the underlying data at request time.
* [Get Unified Metrics in Workspace](get-aggregate-formulas-in-workspace.md) - Returns the full list of aggregate formulas (Unified Metrics) across every view/table in the workspace, along with the table that owns each formula.
