# Columns

* [Columns](overview.md) - APIs for adding, renaming, reordering, showing, hiding, deleting, and sorting columns.

# Concepts

* [Add Column](add-column.md) - Adds one or more columns to an existing table.
* [Delete Column](delete-column.md) - Permanently deletes a column from the specified table.
* [Get Column Dependents](get-column-dependents.md) - Returns every view, custom formula column and aggregate formula that depends on the specified column.
* [Hide Columns](hide-columns.md) - Hides one or more columns of the specified table.
* [Rename Column](rename-column.md) - Renames the specified column of a table.
* [Reorder Columns](reorder-columns.md) - Changes the display order of the columns of the specified table.
* [Show Columns](show-columns.md) - Makes one or more previously hidden columns visible again in the specified table.
* [Sort Data by Columns](sort-data-by-columns.md) - Sets the default sort order for the rows of the specified table.
