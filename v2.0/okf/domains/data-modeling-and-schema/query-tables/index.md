# Query Tables

* [Query Tables](overview.md) - APIs for creating, editing, and retrieving query table details.

# Concepts

* [Create Query Table](create-query-table.md) - Creates a new query table by executing a user-supplied SQL SELECT statement against existing tables/views in the workspace.
* [Edit Query Table](edit-query-table.md) - Updates the SQL definition and/or folder of an existing query table.
* [Get Query Table Details](get-query-table-details.md) - Returns the full metadata of a query table, including its SQL definition, the tables involved, and its column schema.
* [Get Query Tables](get-query-tables.md) - Returns a paginated, filterable, sortable list of all query tables in the workspace.
