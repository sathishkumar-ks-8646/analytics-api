# Slideshow Management

* [Slideshow Management](overview.md) - APIs for creating, updating, deleting, and listing slideshows and their URLs.

# Concepts

* [Create Slide Show](create-slideshow.md) - Creates a slideshow in the specified workspace from the given set of views, and returns its ID along with the URL through which it can be accessed.
* [Delete Slide Show](delete-slideshow.md) - Deletes the specified slideshow from the workspace.
* [Get Slide Info](get-slideshow-details.md) - Returns the details of the specified slideshow, including its slide key, its access type, and the IDs of the views it contains.
* [Get Slide URL](get-slideshow-url.md) - Returns the URL through which the specified slideshow can be accessed.
* [Get Slide List](get-slideshows.md) - Returns the list of slideshows available in the specified workspace, along with the access type of each of them.
* [Update Slide Show](update-slideshow.md) - Updates the details of the specified slideshow.
