# Slideshow Management

* [Slideshow Management](overview.md) - APIs for creating, updating, deleting, and listing slideshows and their URLs.

# Concepts

* [Create Slide Show](create-slideshow.md) - Creates a new slideshow in the workspace from an ordered set of views, and returns its new ID together with a ready-to-use presentation URL built with default rendering options.
* [Delete Slide Show](delete-slideshow.md) - Deletes a slideshow from the workspace.
* [Get Slide Info](get-slideshow-details.md) - Returns the full definition of a single slideshow: its name, its access type, its secret slide key, and the ordered list of view IDs it contains.
* [Get Slide URL](get-slideshow-url.md) - Builds and returns the presentation URL for an existing slideshow.
* [Get Slide List](get-slideshows.md) - Returns every slideshow that exists in the workspace, with its ID, name, and access type.
* [Update Slide Show](update-slideshow.md) - Updates an existing slideshow: renames it, replaces its set of views, changes its access type, and/or rotates its slide key.
