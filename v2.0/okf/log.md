# Bundle Update Log

## 2026-10-29
* **Added**: `/foundations/api-units.md` - API unit cost and frequency limit reference covering all 205 endpoints: per-endpoint unit cost and row basis, the `DML` / `BULK` / `METADATA` unit categories with their per-minute request ceilings, the variable (format- and importType-driven) costs for export, import and Copy Workspace, the endpoint-specific throttles, and the zero-cost endpoints. Sourced from the API gateway configuration (`webapps/db/WEB-INF/gatewayxmls/zagateway-restapi.xml`) and the URL security configuration (`webapps/db/WEB-INF/securityxmls/security-restapi.xml`). Internal-service routes and service unit exemptions in those files were deliberately excluded.
* **Updated**: every endpoint concept now carries an `api.api_units` block in its front matter and "API units" / "Frequency limit" rows in its Endpoint table; every group overview carries an "API units" column and per-endpoint unit metadata; `/endpoint-catalog.md` gained "API units" and "Unit category" columns and `/references/endpoint-catalog.json` gained a per-endpoint `api_units` object plus a top-level `api_unit_categories` map. The OpenAPI copies under `/references/openapi/` carry the same data in `x-zenesis-security` on each operation and `x-api-unit-categories` at the document root, matching their upstream in `zenesis-oas/` byte for byte.
* **Corrected**: `/foundations/rate-limits-and-quotas.md` - the Create Query Table and Edit Query Table throttles are 20 requests/user/minute with a 10-minute lockout (previously documented as 7 requests/user/minute with a 5-minute lockout), Read Dashboard Metadata has a 10-minute lockout (previously blank), and the Sync Data and Refetch Data throttles (5 requests/minute, 5-minute lockout) were added.

## 2026-10-27
