OrgAPI

Organization-scoped calls: users, roles, admins, subscription and resource usage, organization-wide workspace listings and organization-wide security controls. 23 methods.

OrgAPI exposes 23 methods. Method names are PascalCase (exported) and identifiers are string.

Methods#

ActivateUsers, AddUsers, ChangeUserRole, CreateCustomRole, CreateWorkspace, DeactivateUsers, DeleteCustomRole, GetAdmins, GetAutoMLAnalysis, GetCustomRoles, GetLinkedWorkspaces, GetMetaDetails, GetOrgAccessRestrictions, GetOrgDashboards, GetOrgRecentItems, GetOrgWorkspaces, GetResourceDetails, GetSubscriptionDetails, GetUsers, GetViewDetails, RemoveUsers, UpdateCustomRole, UpdateOrgAccessRestrictions

ActivateUsers#

Activate users in the specified organization.

ParameterDescription
emailidsThe email address of the users to be activated.
configContains any additional control configurations.

AddUsers#

Add users to the specified organization.

ParameterDescription
emailidsThe email address of the users to be added.
configContains any additional control configurations.

ChangeUserRole#

Change role for the specified users.

ParameterDescription
emailidsThe email address of the users.
roleName of the role to be updated. Can be one of "USER"/"VIEWER"/"ORGADMIN".
configContains any additional control configurations.

CreateCustomRole#

Create a new custom role in the organization.

ParameterDescription
rolenameName of the custom role.
accesstypeAccess type for the custom role.
permissionsPermissions configuration for the custom role.
configContains any additional control configurations.

Returns — Returns the new custom role id.

CreateWorkspace#

Create a blank workspace in the specified organization.

ParameterDescription
workspacenameName of the workspace to be created.
configContains any additional control configurations.

Returns — Returns the new workspace id.

DeactivateUsers#

Deactivate users in the specified organization.

ParameterDescription
emailidsThe email address of the users to be deactivated.
configContains any additional control configurations.

DeleteCustomRole#

Delete the specified custom role from the organization.

ParameterDescription
roleidId of the custom role to be deleted.

GetAdmins#

Returns list of admins for a specified organization.

Returns — Returns orgadmin list as interface.

GetAutoMLAnalysis#

Returns list of automl analysis for the specified organization.

Returns — Returns AutoML analysis list as interface.

GetCustomRoles#

Returns list of all custom roles available in the organization.

Returns — Returns custom role list as interface.

GetLinkedWorkspaces#

Returns list of linked workspaces available in the specified organization.

Returns — Returns the linked workspaces list as interface.

GetMetaDetails#

Returns details of the specified workspace/view.

ParameterDescription
workspacenameThe name of the workspace.
viewnameThe name of the view.

Returns — Returns details as interface.

GetOrgAccessRestrictions#

Returns the access restriction settings configured for the organization.

Returns — Returns the organization access restriction settings as interface.

GetOrgDashboards#

Returns the dashboards of the specified organization that the authenticated user may read,

ParameterDescription
configContains any additional control configurations.

Returns — Returns the dashboards of the page along with the paging details as map.

GetOrgRecentItems#

Returns the views the authenticated user opened most recently in the specified organization,

Returns — Returns view list as interface.

GetOrgWorkspaces#

Returns the workspaces of the specified organization that the authenticated user can reach.

Returns — Returns workspace list as interface.

GetResourceDetails#

Returns resource usage details of the specified organization.

Returns — Returns details as interface.

GetSubscriptionDetails#

Returns subscription details of the specified organization.

Returns — Returns details as interface.

GetUsers#

Returns list of users for the specified organization.

Returns — Returns user list as interface.

GetViewDetails#

Returns details of the specified view in the organization.

ParameterDescription
viewidThe ID of the view.
configContains the control configurations.

Returns — Returns the view details as interface.

RemoveUsers#

Remove users from the specified organization.

ParameterDescription
emailidsThe email address of the users to be removed.
configContains any additional control configurations.

UpdateCustomRole#

Update the existing custom role in the organization.

ParameterDescription
roleidId of the custom role to be updated.
rolenameNew name for the custom role.
accesstypeNew access type for the custom role.
permissionsNew permissions configuration for the custom role.
configContains any additional control configurations.

UpdateOrgAccessRestrictions#

Update the access restriction settings of the organization.

ParameterDescription
configContains the access restriction configurations to be updated.
