AnalyticsClient

The entry point. 12 methods.

Critical

Construct this once

Creating a client per request exhausts the OAuth token allowance within ten calls. See Authentication.

AnalyticsClient exposes 12 methods. Method names are PascalCase and identifiers are long.

Methods#

GetBulkInstance, GetConnectionTimeout, GetOrgInstance, GetReadTimeout, GetViewInstance, GetWorkspaceInstance, SetAccountsServerURL, SetAnalyticsServerURL, SetConnectionTimeout, SetDebugLogPath, SetProxy, SetReadTimeout

GetBulkInstance#

Creates a new BulkAPI instance.

ParameterDescription
orgIdThe ID of the organization.
workspaceIdThe ID of the workspace.

Returns (IBulkAPI) — BulkAPI instance.

GetConnectionTimeout#

Returns the timeout until a connection is established.

Returns (int) — The timeout value.

GetOrgInstance#

Creates a new OrgAPI instance.

ParameterDescription
orgIdThe ID of the organization.

Returns (IOrgAPI) — OrgAPI instance.

GetReadTimeout#

Returns the read timeout value which will wait for the packet to receive from the server end.

Returns (int) — The timeout value.

GetViewInstance#

Creates a new ViewAPI instance.

ParameterDescription
orgIdThe ID of the organization.
workspaceIdThe ID of the workspace.
viewIdThe ID of the view.

Returns (IViewAPI) — ViewAPI instance.

GetWorkspaceInstance#

Creates a new WorkspaceAPI instance.

ParameterDescription
orgIdThe ID of the organization.
workspaceIdThe ID of the workspace.

Returns (IWorkspaceAPI) — WorkspaceAPI instance.

SetAccountsServerURL#

Sets the accounts server URL.

ParameterDescription
serverUrlZohoAccounts server URL

SetAnalyticsServerURL#

Sets the analytics server URL.

ParameterDescription
serverUrlZohoAnalytics server URL

SetConnectionTimeout#

Sets the timeout until a connection is established.

ParameterDescription
timeoutThe timeout value.

SetDebugLogPath#

Sets the file path for the debug log. Call this before making any API calls.

ParameterDescription
logFilePathFull path to the log file. E.g. "C:\Logs\ZohoAnalytics.log"

SetProxy#

To specify the proxy server details.

ParameterDescription
proxyHostThe hostname/IP address of the proxy server.
proxyPortThe proxy server port.
proxyUsernameThe user name for proxy-server authentication.
proxyPasswordThe password for proxy server authentication.

SetReadTimeout#

Sets the read timeout which will wait for data response from the server end.

ParameterDescription
timeoutThe timeout value.
