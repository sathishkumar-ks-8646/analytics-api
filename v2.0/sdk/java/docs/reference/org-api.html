OrgAPI

Organization-scoped calls: users, roles, admins, subscription and resource usage, organization-wide workspace listings and organization-wide security controls. 23 methods.

OrgAPI exposes 23 methods. Method names are camelCase, matching the endpoint title and identifiers are long.

Methods#

activateUsers, addUsers, changeUserRole, createCustomRole, createWorkspace, deactivateUsers, deleteCustomRole, getAdmins, getAutoMLAnalysis, getCustomRoles, getLinkedWorkspaces, getMetaDetails, getOrgAccessRestrictions, getOrgDashboards, getOrgRecentItems, getOrgWorkspaces, getResourceDetails, getSubscriptionDetails, getUsers, getViewDetails, removeUsers, updateCustomRole, updateOrgAccessRestrictions

ParameterDescription

configContains any additional control configurations. Can be null.

getOrgDashboards#

Returns the dashboards of the specified organization that the authenticated user may read, across the workspaces the user can reach or across the workspaces named in workspaceIds.

ParameterDescription
configContains any additional control configurations. Can be null.

Returns (JSONObject) — A JSONObject holding the dashboards of the page and the paging details.

Raises — ServerException; ParseException; IOException; JSONException

getOrgRecentItems#

Returns the views the authenticated user opened most recently in the specified organization, newest first. At most 20 items are returned.

Returns (JSONArray) — A JSONArray of recent items.

Raises — ServerException; ParseException; IOException; JSONException

getOrgWorkspaces#

Returns the workspaces of the specified organization that the authenticated user can reach. An Account Admin and an Organization Admin receive every active workspace of the organization, every other user receives only the workspaces shared with them.

Returns (JSONArray) — A JSONArray of workspaces.
