AnalyticsClient

The entry point. 4 methods.

Critical

Construct this once

Creating a client per request exhausts the OAuth token allowance within ten calls. See Authentication.

AnalyticsClient exposes 4 methods. Method names are snake_case and identifiers are str.

Methods#

get_bulk_instance, get_org_instance, get_view_instance, get_workspace_instance

get_bulk_instance#

Returns a new C{BulkAPI} instance.

ParameterTypeDescription
org_idstringThe id of the organization.
workspace_idstringThe id of the workspace.

get_org_instance#

Returns a new C{OrgAPI} instance.

ParameterTypeDescription
org_idstringThe id of the organization.

get_view_instance#

Returns a new C{ViewAPI} instance.

ParameterTypeDescription
org_idstringThe id of the organization.
workspace_idstringThe id of the workspace.
view_idstringThe id of the view.

get_workspace_instance#

Returns a new C{WorkspaceAPI} instance.

ParameterTypeDescription
org_idstringThe id of the organization.
workspace_idstringThe id of the workspace.
