Client settings

Configuration

Timeouts, proxies, regions and per-request configuration.

Everything on this page is set on the client and applies to every call made through it.

Timeouts#

Defaults are generous enough for interactive calls but not for large imports or exports. Raise the read timeout before moving large files.

Note

Timeouts are not retries

A timeout aborts the HTTP request; it does not cancel work already started on the server. An import that times out client-side may still land. Check the job status before retrying — see Importing data.

Request configuration#

Supplying an access token directly#

Ruby notes#

  • with_token_store_path stores the access token encrypted on disk, so a process restart reuses the existing token instead of minting a new one. Strongly recommended for short-lived processes such as cron jobs.
