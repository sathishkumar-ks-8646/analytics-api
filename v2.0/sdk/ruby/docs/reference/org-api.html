OrgAPI

Organization-scoped calls: users, roles, admins, subscription and resource usage, organization-wide workspace listings and organization-wide security controls. 23 methods.

OrgAPI exposes 23 methods. Method names are snake_case and identifiers are string.

Methods#

activate_users, add_users, change_user_role, create_custom_role, create_workspace, deactivate_users, delete_custom_role, get_admins, get_automl_analysis, get_custom_roles, get_linked_workspaces, get_meta_details, get_org_access_restrictions, get_org_dashboards, get_org_recent_items, get_org_workspaces, get_resource_details, get_subscription_details, get_users, get_view_details, remove_users, update_custom_role, update_org_access_restrictions

activate_users#

Activate users in the specified organization.

ParameterTypeDescription
email_idsArrayEmail addresses to activate
configHashOptional config

add_users#

Add users to the specified organization.

ParameterTypeDescription
email_idsArrayEmail addresses to add
configHashOptional config

change_user_role#

Change role for the specified users.

ParameterTypeDescription
email_idsArrayEmail addresses to modify
roleStringNew role to assign
configHashOptional config

create_custom_role#

Create a new custom role in the organization.

ParameterTypeDescription
role_nameStringName of the custom role to be created
access_typeStringAccess type for the custom role
permissionsHashPermissions configuration
configHashAdditional control parameters

Returns (String) — Created custom role id

create_workspace#

Create a blank workspace in the specified organization.

ParameterTypeDescription
workspace_nameStringThe name of the workspace
configHashOptional configuration parameters

Returns (Integer) — Created workspace ID

deactivate_users#

Deactivate users in the specified organization.

ParameterTypeDescription
email_idsArrayEmail addresses to deactivate
configHashOptional config

delete_custom_role#

Delete the specified custom role from the organization.

ParameterTypeDescription
role_idStringId of the custom role to be deleted

get_admins#

Returns list of admins for a specified organization.

Returns (Array) — List of organization admins

get_automl_analysis#

Returns all AutoML analyses available in the organization.

Returns (Array) — AutoML analysis list

get_custom_roles#

Returns list of all custom roles available in the organization.

Returns (Array) — Custom roles list

get_linked_workspaces#

Returns list of linked workspaces available in the specified organization.

Returns (Array) — Linked workspaces list

get_meta_details#

Returns metadata details of a workspace or a specific view.

ParameterTypeDescription
workspace_nameStringName of the workspace
view_nameString, nilName of the view (optional)

Returns (Hash) — Metadata details

get_org_access_restrictions#

Returns the access restriction settings configured for the organization.

Returns (Hash) — Organization access restriction settings

get_org_dashboards#

Returns the dashboards of the specified organization that the authenticated user may read, across the workspaces the user can reach or across the workspaces named in workspaceIds.

ParameterTypeDescription
configHashOptional configuration parameters

Returns (Hash) — Dashboards of the page along with the paging details

get_org_recent_items#

Returns the views the authenticated user opened most recently in the specified organization, newest first. At most 20 items are returned.

Returns (Array) — View list

get_org_workspaces#

Returns the workspaces of the specified organization that the authenticated user can reach. An Account Admin and an Organization Admin receive every active workspace of the organization, every other user receives only the workspaces shared with them.

Returns (Array) — Workspace list

get_resource_details#

Returns resource usage details of the specified organization.

Returns (Hash) — Resource usage details

get_subscription_details#

Returns subscription details of the specified organization.

Returns (Hash) — Subscription details

get_users#

Returns list of users for the specified organization.

Returns (Array) — List of users

get_view_details#

Returns details of the specified view in the organization.

ParameterTypeDescription
view_idStringId of the view
configHashOptional configuration parameters

Returns (Hash) — View details

remove_users#

Remove users from the specified organization.

ParameterTypeDescription
email_idsArrayEmail addresses to remove
configHashOptional config

update_custom_role#

Update the existing custom role in the organization.

ParameterTypeDescription
role_idStringId of the custom role to be updated
role_nameStringNew name for the custom role
access_typeStringNew access type for the custom role
permissionsHashNew permissions configuration
configHashAdditional control parameters

update_org_access_restrictions#

Update the access restriction settings of the organization.

ParameterTypeDescription
configHashContains the access restriction configurations to be updated
