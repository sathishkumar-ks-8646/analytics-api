OrgAPI

Organization-scoped calls: users, roles, admins, subscription and resource usage, organization-wide workspace listings and organization-wide security controls. 19 methods.

OrgAPI exposes 19 methods. Method names are camelCase and identifiers are string.

Methods#

activateUsers, addUsers, changeUserRole, createCustomRole, createWorkspace, deActivateUsers, deleteCustomRole, getAdmins, getAutomlAnalysis, getCustomRoles, getLinkedWorkspaces, getMetaDetails, getOrgAccessRestrictions, getResourceDetails, getSubscriptionDetails, getUsers, removeUsers, updateCustomRole, updateOrgAccessRestrictions
