BulkAPI

Data movement: synchronous import and export, batched import for large files, and asynchronous (job-based) import and export. 14 methods.

BulkAPI exposes 14 methods. Method names are PascalCase (exported) and identifiers are string.

Methods#

ExportBulkData, ExportData, GetExportJobDetails, GetImportJobDetails, ImportBulkData, ImportBulkDataAsBatches, ImportBulkDataInNewTable, ImportBulkDataInNewTableAsBatches, ImportData, ImportDataInNewTable, ImportRawData, ImportRawDataInNewTable, InitiateBulkExport, InitiateBulkExportUsingSQL

ExportBulkData#

Download the exported data for the mentioned job id.

ParameterDescription
jobidReturns the export job id.
filepathPath of the file where the data exported to be stored.

ExportData#

Export the mentioned table (or) view data.

ParameterDescription
viewidId of the view to be exported.
responseformatThe format in which the data is to be exported.
filepathPath of the file where the data exported to be stored.
configContains the control configurations.

GetExportJobDetails#

ParameterDescription
jobidId of the export job.

Returns — Returns the export job details as interface.

GetImportJobDetails#

Returns the details of the import job.

ParameterDescription
jobidId of the import job.

Returns — Returns the import job details as interface.

ImportBulkData#

Asynchronously import the data contained in the mentioned file into the table.

ParameterDescription
viewidId of the view where the data to be imported.
importtypeThe type of import. Can be one of - append, truncateadd, updateadd.
filetypeType of the file to be imported.
autoidentifyUsed to specify whether to auto identify the CSV format. Allowable values - true/false.
filepathPath of the file to be imported.
configContains the control configurations.

Returns — Returns the import job id.
