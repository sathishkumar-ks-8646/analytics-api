Quotas & throttles

Limits

Token throttles, per-operation limits, concurrency guards and plan quotas.

Four independent mechanisms limit what an integration can do. They are enforced separately and signal differently.

MechanismScopeSignal
OAuth token throttlePer refresh tokenaccess_denied from Zoho Accounts. See Authentication.
Per-operation throttlesPer user, per operationRequest rejected for a lockout period.
Concurrency guardsOne long-running operation per objectA specific error code such as 18072, 7429, 8132.
Plan quotasPer organizationError when exhausted; visible through Get Resource Details.

Critical

The token throttle is the one that bites first

Ten access tokens per ten minutes per refresh token. It is the limit most integrations hit, and it is entirely avoidable — see Authentication.

Limit

When synchronous export is not allowed

Tables over one million rows, dashboards, query tables and live-connect views cannot be exported synchronously — the call fails with 8133. Use the asynchronous job flow described in Exporting data.

Concurrency guards#

GuardErrorBehaviour
One refetch per table18072A second refetch while one is running is rejected.
One copy per organization7429A second workspace copy is rejected while one runs.
Five export jobs per organization8132A sixth job is rejected.

Waiting is the fix; backing off blindly without checking whether the blocking operation finished is not.

API units#

Every call deducts API units from the organization's plan allowance, with the cost depending on the operation. Current allocation, usage and remainder come back from Get Resource Details under resourceName: "apiUnits".

Warning

Single-row APIs are expensive at volume

Add Row, Update Row and Delete Row cost one API unit per row. Loading data row by row will exhaust the quota quickly — use the import APIs instead. See Importing data.

Plan quotas visible through the API#

users, roUsers, workspaces, rows, queryTables, archivedrows, scheduledImports, scheduledEmails, apiUnits, scheduledAlerts, scheduledSnapshots, archiveschedule, financeMultiorgImports, privateLinks, actionsByFlow. A value of "Unlimited" means no cap.
