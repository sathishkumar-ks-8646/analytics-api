Zoho Analytics · Ruby

Introduction

The Ruby client for Zoho Analytics REST API v2 — 225 methods across five scoped surfaces.

The Zoho Analytics Ruby client wraps REST API v2. It carries your OAuth credentials, keeps the access token alive, and exposes the API as four scoped instances hanging off one client object.

Critical

Create the client once, not per request

Constructing a new client on every request will get your integration blocked by Zoho Accounts within minutes. Read Authentication before you ship anything.

  1. Getting started — install, construct a client, make a first call.
