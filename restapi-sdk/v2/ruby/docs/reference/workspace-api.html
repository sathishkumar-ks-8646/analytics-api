WorkspaceAPI

Workspace-scoped calls: views, folders, tags, query tables, variables, slideshows, email schedules, data alerts, backups, linked workspaces, sharing, workspace membership and workspace security controls. 116 methods.

WorkspaceAPI exposes 116 methods. Method names are snake_case and identifiers are string.
